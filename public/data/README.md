# Datos locales (mocks)

Acá van los JSON que simulan las respuestas del backend mientras no está conectado.
Los servicios de `src/services/` los leen con `fetch('/data/archivo.json')`.

Qué archivo crea cada persona y qué forma tiene: `docs/contrato-api.md`, secciones 2 a 8.

**Regla:** los nombres de campo y los tipos tienen que ser exactamente los del DTO del backend.
